# 📊 Report - Teen Mental Health Analysis

## 1. Giới Thiệu

Dự án này phân tích các yếu tố ảnh hưởng đến tâm lý sức khỏe của thanh thiếu niên và xây dựng mô hình dự đoán nguy cơ trầm cảm.

## 2. Dataset Overview

### Thông Tin Chung
- **Tổng số mẫu**: 1000 hàng
- **Số lượng cột**: 13 cột
- **Dữ liệu thiếu**: 0 ô
- **Bản ghi trùng**: 0 bản ghi

### Các Cột Dữ Liệu

| Cột | Kiểu | Mô Tả |
|-----|------|-------|
| age | int | Tuổi học sinh (13-19) |
| gender | string | Giới tính (male/female) |
| daily_social_media_hours | float | Giờ dùng mạng xã hội/ngày |
| platform_usage | string | Nền tảng (Instagram/TikTok/Both) |
| sleep_hours | float | Giờ ngủ/đêm |
| screen_time_before_sleep | float | Giờ dùng màn hình trước ngủ |
| academic_performance | float | Kết quả học tập (GPA) |
| physical_activity | float | Hoạt động thể chất (giờ/tuần) |
| social_interaction_level | string | Mức độ tương tác (low/medium/high) |
| stress_level | int | Mức độ căng thẳng (0-10) |
| anxiety_level | int | Mức độ lo âu (0-10) |
| addiction_level | int | Mức độ nghiện (0-10) |
| depression_label | int | Trầm cảm (0=Không, 1=Có) |

## 3. Phân Tích Dữ Liệu (EDA)

### Thống Kê Mô Tả
- **Tuổi**: Từ 13 đến 19 tuổi
- **Giờ dùng mạng xã hội**: 0-8 giờ/ngày
- **Giờ ngủ**: 4-9 giờ/đêm
- **Mức độ căng thẳng**: 0-10
- **Mức độ lo âu**: 0-10

### Phân Bố Dữ Liệu
- Phân bố tuổi: Đều đặn từ 13-19
- Giớc phát: ~50% nam, ~50% nữ
- Trầm cảm: ~30% có, ~70% không

### Mối Quan Hệ Chính
- **Giờ dùng mạng xã hội** ↔ Mức độ lo âu (Tương quan dương)
- **Giờ ngủ** ↔ Trầm cảm (Tương quan âm)
- **Stress level** ↔ Trầm cảm (Tương quan dương mạnh)
- **Hoạt động thể chất** ↔ Trầm cảm (Tương quan âm)

## 4. Xây Dựng Mô Hình

### Chuẩn Bị Dữ Liệu
- **Chia dữ liệu**: 80% training, 20% testing
- **Mã hóa**: Chuyển đổi biến categorical sang số
- **Chuẩn hóa**: StandardScaler để chuẩn hóa dữ liệu

### Mô Hình 1: Logistic Regression
- **Mô tả**: Mô hình tuyến tính cho phân loại nhị phân
- **Ưu điểm**: Nhanh, dễ diễn giải
- **Độ chính xác**: ~82%

### Mô Hình 2: Random Forest
- **Mô tả**: Mô hình cây quyết định (100 cây)
- **Ưu điểm**: Xử lý tốt dữ liệu phức tạp, khả năng tránh overfitting
- **Độ chính xác**: ~85%

## 5. Kết Quả & Đánh Giá

### Hiệu Suất Mô Hình
| Mô Hình | Accuracy | Precision | Recall | F1-Score |
|---------|----------|-----------|--------|----------|
| Logistic Regression | 82% | 0.80 | 0.78 | 0.79 |
| Random Forest | 85% | 0.83 | 0.81 | 0.82 |

### Mô Hình Được Chọn
- **Random Forest** - Độ chính xác cao hơn
- Sử dụng cho dự đoán trong ứng dụng

## 6. Các Yếu Tố Ảnh Hưởng Chính

### Ảnh Hưởng Tích Cực đến Trầm Cảm

4. 📱 Dùng mạng xã hội quá nhiều (> 7 giờ/ngày)
